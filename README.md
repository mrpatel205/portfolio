# mrpatel.com — Holding Page

Temporary holding page for [mrpatel.com](https://mrpatel.com) while the full portfolio is in progress.

A single static `index.html` with no build step — Calistoga/Inter via Google Fonts, an entrance animation, and a link to [LinkedIn](https://www.linkedin.com/in/misterpatel/).

## Deployment (Cloudflare Pages)

- **Build command:** none
- **Build output directory:** `/` (repo root)

No framework, no dependencies — just deploy the static file as-is.
